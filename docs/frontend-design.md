# Noema 前端设计

## 已确认的视觉基准

采用 ARTEX 默认浅色主题和用户确认的项目页、登录页概念稿。参考本地 `D:/github_rep/ARTEX/web/src/app/globals.css` 与 `screenshots/dashboard.png`、`screenshots/tasks.png`，不引入 ARTEX 的业务功能或品牌素材。

项目页基准：[workspace-concept.png](design-assets/workspace-concept.png)。登录页基准：[login-concept.png](design-assets/login-concept.png)。概念图中的项目名称和日期仅用于排版；应用始终读取实际数据。

| 内容背景   | `#FFFFFF` |
| 侧栏       | `#FAFAFA` |
| 选中、悬停 | `#F5F5F5` |

## 布局与交互

- 桌面侧栏宽 224px；主区顶部为面包屑，内容区标题与主操作同排，下一排搜索、排序或筛选、刷新。数量单独一行，项目列表显示名称、更新时间和更多操作。
- 排序与筛选共用 Radix Select：按钮固定 144px，文字与箭头作为一组居中，展开菜单同宽；选项使用对称留白、浅灰高亮和勾选标记，支持键盘选择与 Escape 关闭。项目空状态仅保留顶部黑色新建按钮，搜索无结果保留清除搜索。
- 剧集沿用同一框架，显示集序、名称、状态与更新时间。灰色草稿、蓝色制作中、绿色已完成，均配文字与状态点。
- 登录与注册采用 52:48 双栏：左侧品牌、标题与分镜纸雕，右侧邮箱密码表单。标题和表单均为真实 HTML，插画不包含 UI 文字。
- 768px 以下隐藏登录插画；工作台侧栏变为有焦点约束、Escape 关闭和触发按钮焦点恢复的抽屉。选择项目后关闭，窗口扩大为桌面尺寸后自动关闭。
- 窄屏项目更新时间移到名称下方，剧集状态移到名称下方。短窗口允许页面滚动；侧栏最近项目独立滚动，账号和退出入口保持可见。
- 保留现有注册、登录、会话恢复、项目和剧集管理、搜索筛选、校验、删除确认、失败保留表单与重试逻辑。无 API 或数据库变更。

## 原创素材

2026-11-05 使用内置 Image Gen 生成，素材在本地加载。

- `design-assets/noema-icon-original.png`：透明外缘、黑色圆角方形、白色几何 N。提示词核心：简洁电影画框意象，粗笔画，16px 可识别，无额外文字。
- `design-assets/storyboard-original.png`：浅灰背景上的白色分镜画框与胶片纸雕。提示词核心：高调中性灰白摄影、柔和日光、建筑门洞与地平线、上方留白，无文字或品牌。
- 应用资源位于 `apps/desktop/src/renderer/public/brand/`：16、32、48、180、256、512px PNG；含 16/32/48/64/128/256px 的 ICO；压缩 WebP 插画。原始 PNG 保存在文档目录，不随应用发布。
- 同一图标用于品牌、favicon、Apple touch icon 与 Electron 窗口。`img-src 'self'` 允许本地资源；其余内容安全限制保留。

## 设计稿对照记录

使用真实 Electron 渲染器截图和 `view_image` 同轮检查设计稿与实现，包含原稿实际尺寸 1487×1058；没有使用浏览器模拟替代 Electron 的 IPC 和认证桥接。

| 检查项 | 实现与处理                                                                                       |
| ------ | ------------------------------------------------------------------------------------------------ |
| 配色   | 白色主区、浅灰侧栏、黑色按钮与中性灰边框；没有沿用旧蓝灰色或探索期绿色主题。                     |
| 结构   | 224px 侧栏、面包屑、标题与主操作、搜索工具栏、数量与列表按确认稿顺序组织。                       |
| 字号   | 使用约定的 32px 工作区标题、17px 项目名、14px 控件；登录标题 32px、表单 16px，适合实际桌面尺寸。 |
| 品牌   | 按新增品牌要求在工作区和登录页加入 N 图标；16/32/48px 预览检查可辨识。                           |
| 插画   | 改为完整等比显示，修复最初 cover 裁切；沿用原始素材的光影，没有添加色罩。                        |
| 列表   | 细分隔线与 10px 外圆角，使用真实名称和时间；长名称和窄屏更新时间可读。                           |
| 交互   | 抽屉独立使用左侧布局变体，修复居中弹窗残余位移；Escape、选择导航和扩宽窗口均可关闭。             |

有意差异：真实数据代替概念图示例；新增 N 品牌图标；系统中文字体代替生成图的栅格字形；项目数量保留原有“5 个项目”等动态文案。其余首屏可见文案没有新增营销标签。状态和表单为可访问 HTML，不使用截图代替界面。

筛选对齐回归：逐项切换最近更新、项目名称及全部剧集状态，检查按钮宽度不变，文字与箭头组合中心相对按钮中心偏差小于 1px。截图 `out/sort-menu.png` 同时检查收起按钮和展开菜单。
